> **A flagship Data Analytics Capstone Project that demonstrates how real business problems are solved using a structured, business-first analytics methodology.**

This repository showcases an end-to-end Warehouse Operations & Inventory Analytics case study developed using the **Data Analytics Project Methodology (DAPM) v0.2.1**.

Rather than starting with dashboards, the project follows the complete analytics lifecycle—from understanding the business problem to delivering evidence-based business recommendations.

Every phase follows DAPM, ensuring that business understanding, data preparation and analysis are completed in a structured and reproducible manner.

# Project Methodology

This project follows the **Data Analytics Project Methodology (DAPM) v0.2.1**.

DAPM is a structured analytics framework that guides projects from business understanding through executive reporting using clearly defined phases, standardised documentation and professional engineering practices.

# Project Principles

The project follows five guiding principles throughout the analytics lifecycle.

- Business before Technology
- Observe before Cleaning
- Clean before Validation
- Validate before Analysis
- Evidence before Recommendation
